# 使用手册

## 首次启动

打开 App 后看到主页，分为 4 个区域：
- **默认网页** - 4399 / 7k7k / 灵动游戏 等
- **继续上次** - 最近玩过的 8 个游戏
- **收藏** - 你 ☆ 的游戏
- **本地游戏** - 你手动添加的 SWF 文件

## 添加本地游戏

### 方式 A：单个文件

1. 侧边菜单 → **本地游戏**
2. 点 **+ 文件**
3. 选择 `.swf` 文件（可多选）

### 方式 B：整个文件夹

1. 侧边菜单 → **本地游戏**
2. 点 **+ 文件夹**
3. 选择包含 SWF 的文件夹
4. 等待扫描完成

> 小于 4MB 的文件直接缓存在本地，立即可玩。大文件会作为 Blob 引用，加载稍慢但能完整播放。

## 播放游戏

点击任意卡片：
- 普通卡片 → **直接播放**
- 网页卡片 → 在内置 WebView 中打开

播放界面：
- 顶栏：返回 / 标题 / 引擎切换 / 画质 / 全屏
- 画布：游戏本体
- 底栏：刷新 / 收藏 / 历史 / 虚拟按键 / 更多
- 屏幕上的虚拟按键：可拖动、缩放、修改按键

## 切换引擎

播放界面顶栏 → 点 **引擎标签** → 选择 Ruffle / Waflash / swf2js

> 不同引擎对同一 SWF 的兼容性不同。Ruffle 是最稳的。

## 画质 / 画面比例

**方式 A：**
- 播放界面 → ⚙️ 按钮 → 选画质 / 比例

**方式 B：**
- 侧边菜单 → **引擎设置** → 选默认引擎 → 改画质 / 比例

## 虚拟按键

### 移动 / 缩放

**进入编辑模式：** 侧边菜单 → 虚拟按键 → 「进入编辑模式」

- 拖动：移动
- 拖右下角：缩放
- 长按：弹出操作菜单

### 切换摇杆 ↔ 方向键

- 虚拟按键页 → 「方向控制方式」→ 选 摇杆 / 方向键
- 或者编辑时长按摇杆 → 「切换为方向键」

### 切换 WSAD ↔ ↑↓←→

- 虚拟按键页 → 「WSAD / ↑↓←→」
- 同样可在编辑菜单里切换

### 修改 / 添加 / 删除独立按键

- 虚拟按键页 → 「+ 添加按键」→ 选键盘上的任意按键
- 长按某个按键 → 修改 / 删除

> 选键界面是一个**完整的虚拟键盘模型**，包含主键盘、数字键、方向键。你也可以搜索按键名称（如搜 "J"、"Space"）。

## 收藏 / 历史

- **收藏**：游戏卡片左上的 ☆ 按钮
- **历史**：自动记录最近 200 条
- **去重**：相同 URL 在历史里只保留最新一条

## 默认 / 自定义网页

### 默认网页
内置：
- 4399 电脑版
- 4399 手机版
- 7k7k 小游戏
- 17yy
- 灵动游戏
- 多多游戏
- Flash 1890
- Ruffle 演示
- Newgrounds

每个卡片点击后可以「打开」或「设为默认」。设默认后从主页「打开当前默认页」按钮可一键打开。

### 自定义网页

1. 侧边菜单 → **自定义网页** → **+ 添加**
2. 输入：名称 / URL / 图标 / 说明 / 模式
3. 添加后即可在「自定义网页」列表里点开

> 模式说明：
> - 桌面模式：让网页认为在 PC 浏览器
> - 移动模式：让网页认为在手机
> - 兼容模式：按系统设置
> - 自动：按屏幕宽度

## 广告拦截

- **网络层**：原生拦截（在 `AdBlocker.java`）
- **DOM 层**：JS 注入（`modules/adblock.js`）
- **自定义规则**：
  - 「设置 → 广告拦截」里可加主机名 / URL 片段
  - 也可清空自定义，恢复默认 200+ 规则

## 缓存

- 「设置 → 缓存」→ 清空所有 WebView 缓存
- 也会清空 localStorage、Service Worker

## 主题 / 缩放

- 暗色 / 亮色 / 跟随系统 - 「设置 → 显示」
- 全局页面缩放 - 「设置 → 显示 → 页面缩放」拖动 slider

## 网页内操作

- 单击/双击 = 正常交互
- 长按 = 弹出右键菜单
- 三个小圆点按钮 = 复制链接 / 分享 / 外部打开
